## Assignment Overview

This project is an investigative, practical study of computer systems and software engineering fundamentals. Across nine structured missions, it explores:
1. Workspace setup and Git-based project governance.
2. The Input-Processing-Output-Storage (IPOS) model and hardware/software classification.
3. Command-line interface (CLI) mastery, file stream manipulation, flags, and pipes.
4. Operating system architecture, process scheduling, memory, file permissions, and storage.
5. Compilation vs. interpretation execution models with Python.
6. Binary, decimal, and hexadecimal number representations and character encodings (ASCII & UTF-8).
7. Distributed version control workflows, branch isolation, and Pull Requests.
8. Computer networking topologies, protocols, DNS resolution, and the web communication lifecycle.
9. Final validation, structured reporting, and submission compliance.

Each mission is self-contained in its designated folder with an independent `README.md` adhering to the required 9-point reporting specification. Every mission is completed, documented, and committed in sequential order.

## Instructions for Running the Python Number Converter

The interactive number conversion tool is located in `mission-05-numbers-data/`. To execute the program:

```bash
# Navigate to the mission directory
cd mission-05-numbers-data

# Run using Python 3
python3 number_converter.py
```

Follow the on-screen prompt to enter any positive decimal integer. The program will output the binary (`bin()`) and hexadecimal (`hex()`) representations.
